Snackbar review

Every snack in Crew and Feedback, judged against the rules below. Read from main on 24 Nov 2026.

Rules
  1. A snack only for something the user just did whose result the screen doesn't show: a page closed, a row left, tix moved, someone else was told.
  2. If a row, tile, thread or page changes to show it, no snack.
  3. Never from background work: loads, resumes, live updates, uploads. Those show on the row or page.
  4. Errors say what failed and what to do, with Try again when it can be retried.
  5. No connection is always: “Couldn't reach TestTrack. Check your connection.”
  6. One snack per action. Same event, same words, everywhere.
  7. Done = it worked. Info = nothing failed, just know this. Error = it failed. Offline (sticky) only on a page that keeps working offline.
  8. Short sentences, full stop at the end, no Thanks, no dashes.

Also found

  • Take-out dialog (CrewPage.kt:387) says “Your 2 tix come back” even for a seat placed free. It should use the seat's own charge.
  • Snack timers keep running while TestTrack is in the background, so a snack posted while the user is in Play can run out unseen. Another reason to keep snacks off background work.
  • Report, answer and take out will keep the row's spinner until the fresh list is in, as Withdraw already does, so the snack and the row agree.
