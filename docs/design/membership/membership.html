The testers group: one sheet, every state

Today the group check is drawn by five separate Ask calls, one per state, and each Ask is its own Dialog window. Every time the state changes, one window closes and another opens: the "Checking your tester access" box goes, the join box comes, then the result box. That is the "multiple dialogs" feeling.

The new flow is one sheet in the same frame as the sign-in sheet. It opens once, stays open while you go to the browser and back, and only its inside changes, with a short cross-fade and the height easing between states. Light and dark at 392dp, one 360dp check. The email is a stand-in.

Sheet or dialog

Both options carry the same states and copy. They differ only in the frame.

Option A: a sheet (recommended)

Same frame, colour and motion as the sign-in sheet (PickerSheet with sheet, sheetLine, live-region title, AnimatedContent). Joining the group is step 2 of the same checklist that sign-in is step 1 of, so the two read as one family. The button sits at the bottom under the thumb, the sheet grows smoothly as the content changes, and it waits calmly behind the browser.
Cost: one new file in the sign-in pattern; the old JoinGroupAsk test needs rewriting.

Option B: one dialog

The current Ask frame, but drawn once with the content switching inside it. Smaller change, keeps the robot head.
Cost: the account row, three steps and two hints make it tall for a dialog (the house rule keeps dialogs for a question with a few answers); a centred card that grows moves in both directions; two side-by-side pills squeeze at 360dp; and it looks unlike the sign-in sheet that comes right before it.

Option A: every state

How it reads: the title says where things stand, the tile beside it takes the tone (neutral, green, amber, red), and the account row stays in the same place in every state so the eye has an anchor. Only the line under the email, the steps and the button change. One filled button per state at most.

Where it opens, and which state it starts on

  1. Crew, Open tab, "Next: Join the testers group" and Me, Testers group row (not a member): straight to S2 Join. No checking face. A quiet check runs behind it; a yes moves the sheet to S4, anything else leaves S2 alone (a failed background check is not shown).
  2. A gate (take a seat, open, open all, install, update, feedback in a crew, a review in Circle or the Feed, "Put it in a crew" on an app page) when the phone has no remembered yes: S1 Checking, then S4 (and the tapped action runs), S2, or S6.
  3. Back from the browser after "Open the group": S3 right away, then S4, S5 or S6.
  4. "I already joined" on S2: S3, then the same three outcomes.
  5. Signed out: never opens. A gate signed out goes to sign-in first, as today, and the checklist shows "Sign in" before the group. If the account signs out or changes while the sheet is up, it closes and the answer is dropped.
  6. Closing by swipe, scrim or Back at any point leaves the account unverified, as today. Nothing is locked.
