My apps: tile options

My apps is the owner's own shelf. Each app can be in a crew, have a feedback request on Circle, both, or neither, and it can be a closed test or live, verified or not. When the owner opens this tab they want four answers from each tile, so every option is judged on them.

1. Does this app need me now?2. What is running, and how far along?3. Closed test or live?4. What is already done?

Every phone shows the same 16 apps, one for each real state an app row can be in today, newest first. Light and dark side by side at 392 dp, real tokens from Tokens.kt, Barlow, Lucide icons as the app uses them. Tiles in A, B and C are 76 dp with a 52 dp icon, the Requests size. A count bubble only appears where the owner has something to do: reviews to check, a request testers couldn't install, or a closed test that is not verified yet.

Most of it is on the app row already (net/AppsWire.kt, backend services/apps.py row()). Two facts the owner most needs are not, so the current tile cannot show them.
